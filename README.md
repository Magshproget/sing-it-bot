# Sing-It Discord Bot 🎤🎶

Discord-бот для голосових каналів, який слухає спів учасників, розпізнає пісню за кількома проспіваними словами чи рядком і автоматично вмикає її у тому ж голосовому каналі. Також підтримує голосові та слеш-команди для керування чергою.

Побудований з урахуванням сучасного протоколу шифрування Discord DAVE (E2EE), апаратного прискорення Apple Silicon Metal та оптимізованого стрімінгу аудіо без потреби у сторонніх серверах на кшталт Lavalink.

---

## ⚡ Архітектура та пайплайн

```
Discord Voice (DAVE E2EE)
  └─ @discordjs/voice receiver: Opus-потік окремо для кожного спікера
       └─ Декодування Opus (48 kHz stereo) → даунсемплінг у 16 kHz mono PCM
            └─ VAD Energy Gate (20 мс кадри, RMS > -36 dBFS, поріг голосу ≥ 400 мс)
                 └─ Chunker (нарізка по 4.5 с або по 1.0 с паузі; відсікання < 0.7 с)
                      └─ whisper.cpp server (large-v3-turbo q5_0, Metal GPU)
                           ├─ Коротка команда? ("стоп", "дали", "назад", "увімкни …") → дія
                           └─ Пошук слів (Genius API з рейт-лімітером та/або SQLite FTS5)
                                └─ Віконний скорер схожості слів (word-window Levenshtein)
                                     └─ yt-dlp (клієнт visionos, Opus/WebM)
                                          └─ Відтворення у тому самому голосовому каналі
```

---

## 🚀 Особливості

- **Apple Silicon Metal Acceleration**: інференс Whisper large-v3-turbo на GPU Mac (~1.1–1.2 с на 4–5 с чанк). Whisper-сервер автоматично піднімається при вході у войс і зупиняється при виході.
- **Підтримка Discord DAVE (E2EE)**: розшифрування вхідного аудіопотоку за допомогою `@snazzah/davey`.
- **Захист від помилкових спрацьовувань**:
  - Відсікання фраз менше 5 слів (звичайна мова ігнорується).
  - Співпадання ≥ 0.85 вмикається миттєво; для діапазону 0.72–0.84 вимагаються два послідовні збіги для однієї пісні.
  - Захист від повторного спрацьовування треку (2 хвилини кулдауну).
- **Подвійний провайдер пошуку текстів**:
  - **Genius API / Web**: вбудований рейт-лімітер (інтервал ≥ 1.5 с), експоненційний backoff при 429, LRU-кеш, очищення назв від перекладів і транслітерацій.
  - **Локальний SQLite FTS5**: миттєвий автономний пошук повнотекстових баз (наприклад, LRCLIB дамп).
- **Швидкий запуск аудіо**: використання `yt-dlp` з клієнтом `visionos` (старт відтворення за 3–4 с замість 9–13 с).
- **Автоматичне відключення**: бот виходить з каналу через 60 с після виходу останньої людини.

## 🛠️ Встановлення та вимоги

### 1. Системні залежності (macOS)
```bash
brew install whisper.cpp yt-dlp ffmpeg
```

### 2. Завантаження моделі Whisper
```bash
mkdir -p models
curl -L -o models/ggml-large-v3-turbo-q5_0.bin \
  "https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin"
```

### 3. Встановлення пакетів Node.js
```bash
npm install
```

---

## ⚙️ Налаштування (`.env`)

Скопіюйте `.env.example` у `.env`:
```bash
cp .env.example .env
chmod 600 .env
```

Заповніть конфігурацію:
```env
# Discord Bot
DISCORD_TOKEN=ваш_токен_бота
DISCORD_CLIENT_ID=ваш_application_id
DISCORD_GUILD_ID=ваш_server_id # Для миттєвої реєстрації слеш-команд

# Провайдер пошуку: "genius", "sqlite" або "both"
LYRIC_SEARCH_PROVIDER=both

# Токен Genius API (рекомендовано, безкоштовно на https://genius.com/api-clients)
GENIUS_ACCESS_TOKEN=

# Шляхи
SQLITE_DB_PATH=data/lyrics.db
WHISPER_MODEL_PATH=models/ggml-large-v3-turbo-q5_0.bin
WHISPER_PORT=8080
```

### Налаштування бота в Discord Developer Portal
1. Scope OAuth2: `bot`, `applications.commands`.
2. Bot Permissions: `View Channels`, `Send Messages`, `Connect`, `Speak`, `Use Voice Activity`.

## 🎮 Керування

### Слеш-команди:
- `/join [channel]` — приєднатися до голосового каналу та слухати співи.
- `/leave` — покинути голосовий канал.
- `/play <query>` — відтворити за назвою або прямим посиланням.
- `/skip` — пропустити трек.
- `/stop` — зупинити музику.
- `/back` — повернутися до попереднього треку з історії.

### Голосові команди (вимовляються окремо у мікрофон):
- `"стоп"` / `"stop"` / `"вимкни музику"` — зупинка відтворення.
- `"дали"` / `"next"` / `"скип"` — пропуск поточної пісні.
- `"назад"` / `"минула"` — увімкнення попереднього треку.
- `"увімкни <назва>"` / `"play <artist title>"` — відтворення за запитом.
